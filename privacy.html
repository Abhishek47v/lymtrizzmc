Privacy Policy – LymtrizzMC Studio

Last updated: 24 October 2026

LymtrizzMC Studio ("the app") is a private tool used only by the owner of the LymtrizzMC YouTube channel to manage that channel. It is not available to other users.

What data the app accesses

With the channel owner's permission (Google OAuth), the app uses the YouTube Data API and YouTube Analytics API to: upload and schedule the owner's own videos; set their titles, descriptions, tags and playlists; update the owner's channel description and keywords; post comments on the owner's own videos; and read the owner's own channel and video statistics.

How data is stored and used

All data stays on the owner's personal computer. The OAuth token is stored in the Windows Credential Manager of that computer. Analytics numbers are stored in a local database only to evaluate the channel's own videos. The app does not sell, share, or transfer any data to third parties and does not use it for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Local data can be deleted by removing the app's data folder from the owner's computer.

Contact

Questions: contact the LymtrizzMC channel via its YouTube About page.
